Features

Built to stay out of your way

No more switching to the browser to look up that one command you always forget.

🧲

Docks to any screen

A small icon on the edge of your monitor. Drag it to either side of any screen; it remembers where you left it.

⚡

Opens instantly

Hover the icon, click it, or press Ctrl+Alt+Space from any app. Move away or press Esc to hide it.

📋

Click to copy

Every command is one click from your clipboard. Search all tabs at once and press Enter to copy the first match.

⭐

Favorites & most used

Star the commands you need most. The ones you copy often show up on their own under Most used.

🧩

Pick your cheat sheets

Choose from 17 cheat sheets on first launch and set the tab order. Change it any time with the ⚙ button.

🌗

Light & dark

Switch themes with one click. Add your own commands by editing simple YAML files.

Install

Up and running in a minute

Download CheatDock-windows.zip and unzip it to any folder, for example Documents\CheatDock.
Run CheatDock.exe and tick the cheat sheets you use on the welcome screen.
Start with Windows (optional): press Win+R, type shell:startup and put a shortcut to CheatDock.exe in that folder.
⚠️ "Windows protected your PC"? CheatDock is new and not code-signed yet, so Windows may show this the first time. Click More info → Run anyway. The full source code is on GitHub if you want to check it.
